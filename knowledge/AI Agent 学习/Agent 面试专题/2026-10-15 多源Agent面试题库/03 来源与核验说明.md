## 出现次数与排序口径

出现次数只统计选定的 3 份面经题单与 5 组公开题库，共 8 个来源单位。面经是发布者自述或整理，未独立确认公司与轮次。题意相同或同一主要考点的明确展开合并；复合题只表示核心考点命中，不代表全部子问原样出现。宽泛相关词、官方技术文档、作者观点、未读图片和 X 搜索索引不计数。同来源多题、目录与正文重复、同仓库多文件及已确认同源转发均只计一次；不同仓库未能确认的共同上游不构成统计独立性保证。

总出现数 = 去重面经来源数 + 去重公开题库来源数；重复次数 = max(总出现数 − 1, 0)。出现 1 次表示有一份匹配材料、重复 0 次；出现 0 次表示当前样本没有匹配证据，不代表题目不重要。

按应用研发与 AI 后端目标，先按重要性等级 P0 → P1 → P2；同级按面经出现数降序，再按公开题库收录数降序；仍并列时按原题号稳定排列，并列项不代表已证明的细微重要性差别。重要性等级沿用原准备判断，频次只是在选定样本中的观察，不能当作全网面试概率。

“面经出现”统计题目在面经帖子中的出现，不是经公司认证的真实面试场次；“公开题库收录”也不是招聘频率。题库正文的来源定位可核对每个计数，无法匹配的补充题明确记 0。

复合题按主要考点匹配，例如 K02 的“合成数据”只在 NC01 明确提出，不能因为另一来源也谈评测集就推断其问过所有子问题。来源只匹配部分主要考点时，在正文列出匹配范围。
