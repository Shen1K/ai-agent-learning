# 未见字符组合专项评测

## 这次到底测什么

测试题中的前两个字符和正确答案都在训练词表中，但这两个前文字符组成的上下文从未在训练集中出现。换句话说：零件见过，组合没见过。

符合条件的测试题共有 **1,623** 道。

## 结果

| 方法 | Top-1 | Top-3 | Top-5 |
|---|---:|---:|---:|
| 单字符 Bigram | 18.42% | 36.48% | 43.62% |
| Trigram→Bigram→Unigram 硬回退 | 18.42% | 36.48% | 43.62% |
| 三级自适应插值 | 18.42% | 37.09% | 43.87% |
| Embedding + 前馈神经网络 | 19.65% | 33.83% | 40.91% |

## 如何理解

- 纯 Trigram 对这些题必然没有参数，因此没有列入比较。
- 回退和插值通过减少上下文要求来给出答案，但会丢失一部分双字符信息。
- 神经模型为每个字符复用同一组向量参数，所以即使某个二字符组合没出现，也仍能执行矩阵计算并输出完整概率分布。这叫参数共享带来的组合泛化。
- 能输出不等于一定答对；Top-k 才衡量这种泛化是否真的有用。

## 神经模型示例

- 未见上下文 `种基`：预测前五 `于、地、其、作、本`，实际 `于`
- 未见上下文 `力机`：预测前五 `构、场、会、的、于`，实际 `制`
- 未见上下文 `工神`：预测前五 `,、。、、、的、于`，实际 `经`

- 未见上下文 `为称`：预测前五 `“、:、为、其、本`，实际 `为`
- 未见上下文 `元通`：预测前五 `用、过、车、常、行`，实际 `过`
- 未见上下文 `入表`：预测前五 `演、,、团、马、布`，实际 `中`
- 未见上下文 `个向`：预测前五 `南、东、北、人、西`，实际 `量`
- 未见上下文 `元都`：预测前五 `是、,、有、和、、`，实际 `通`
- 未见上下文 `都通`：预测前五 `常、过、用、车、湖`，实际 `过`
